# Generated scenes go here

Drop the outputs from `../GENERATION-BRIEF.md` in this folder, named by shot
ID — `1-opening-scene.png`, `checklist-notebook.png`, `9-story-6-hazard.png`
and so on. See `../scenes.json` for the complete list.

Once all fourteen exist, the assembly step lays out the two collage scenes
(`2. Transition to trellis`, `3. Example story trellis`) from these pieces
rather than generating them independently — see `../README.md` for why.
